# Visual provenance

The two PNG figures in `assets/` were created for this repository using the following controlled design path:

1. `graph-engineering-architect` supplied the semantic model: human-owned root goal, explicit edge meaning, independent verification, frozen reality anchor, audit / counter-signal, arbitration, and stop / handoff.
2. `scientific-infographic` supplied the information-design constraints: one reading axis, restrained academic palette, clear hierarchy, short labels, and no decorative elements that compete with the topology.
3. The image-generation brief used only the project contract and the v0.9 case-study artifacts; it did not include credentials, private project files, conversation history or runtime state.
4. The matching Graphviz sources in `docs/` are the exact, editable topology references. The PNGs are presentation views; the `.dot` files are the audit-friendly source of truth for node and edge relationships.

Files:

- [`graph-engineering-agent-builder-architecture.png`](../assets/graph-engineering-agent-builder-architecture.png) — conceptual architecture view.
- [`graph-writing-v0.9-choice-gates-practice.png`](../assets/graph-writing-v0.9-choice-gates-practice.png) — applied v0.9 practice view.
- [`architecture.dot`](architecture.dot) and [`graph-writing-v09.dot`](graph-writing-v09.dot) — editable exact topology sources.

The figures are explanatory engineering documentation. They do not authorize execution, prove independent evidence by themselves, or replace the JSON Graph Spec and validators.
